Detailed Description

Matches the focused application against the pause list.

The pause list contains executable file names (e.g. "chrome.exe") and optional window title fragments. A process name is always required; when title fragments are configured the window title must also contain one of them. Matching is case insensitive for ASCII characters and the list is never empty by default, so the feature is off until the user configures it.
