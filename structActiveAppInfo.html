Detailed Description

Application that owns the window with keyboard focus.

Used by the server to pause computer switching while the user works in specific applications. Both members are empty when the platform can not report it or when no window has focus.

Member Data Documentation

◆ m_fullscreen

bool ActiveAppInfo::m_fullscreen = false

True when the focused window covers its whole monitor.

Only full screen applications pause switching, a windowed application must never trap the cursor on the computer it runs on. Platforms that can not tell leave this false.
